# Contributing

Thanks for considering a contribution!

- Keep the project small, accessible, responsive, and usable without a build step.
- Avoid adding analytics, external services, or dependencies without discussing the privacy and maintenance impact.
- For changes, describe the user problem and include clear reproduction or manual test steps.
- Check the page at desktop and mobile widths; verify checklist editing, task completion, refresh persistence, and print behavior.

For substantial changes, open an issue first to discuss the approach.
